E-Commerce Marketing and Product Performance Analysis

Project Overview This project applies supervised and unsupervised machine learning techniques to analyze a global e-commerce dataset. The goal is to predict revenue, classify customers, and understand key factors influencing sales performance such as pricing, discounts, product categories, and regions.

Dataset Information

Dataset Name: Global E-Commerce Dataset (1M Records)
Source: Kaggle
Link: https://www.kaggle.com/datasets/akrambelha/global-e-commerce-dataset-1m-records
Size: ~1,000,000 rows
Objectives

Predict revenue using regression models
Identify customer segments using clustering
Classify high-value customers
Analyze impact of pricing, discounts, category, and region
Research Questions

Can we predict revenue using product and pricing features?
What customer segments exist?
Which product categories perform best?
How does region affect sales?
Can we classify high-value customers?
How does price impact revenue?
How do discounts affect sales?
